# Material Symbols Outlined

Nova Studio embeds the unmodified `MaterialSymbolsOutlined.ttf` variable font for its command and editor-tool icons. The font is loaded from the Qt resource system; no runtime download or web dependency is used.

- Font: https://raw.githubusercontent.com/google/material-design-icons/10ecc14790612ca8fd164e3f4ffe9c16fc50d5b7/variablefont/MaterialSymbolsOutlined%5BFILL%2CGRAD%2Copsz%2Cwght%5D.ttf

The font defaults are retained: outline style, FILL 0, GRAD 0, weight 400, and optical size 24. Nova renders glyph ink using the active normal or disabled palette color. The codepoint mapping is maintained in `src/ui/theme.cpp`.
